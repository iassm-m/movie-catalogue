# 🎬 Catálogo de Filmes

Este projeto é um **Catálogo de Filmes e Séries** desenvolvido em HTML, CSS e JavaScript, utilizando a **OMDb API** para buscar informações sobre filmes e séries.  
Ele permite pesquisar títulos, favoritar filmes e avaliar cada favorito com estrelas ⭐.

---

## 🚀 Funcionalidades
- 🔍 **Busca de filmes** por título exato ou lista de resultados.
- ❤️ **Favoritar filmes** e salvar no navegador (localStorage).
- ⭐ **Avaliar favoritos** com sistema de estrelas (1 a 5).
- 📊 **Média geral das avaliações** exibida na página de favoritos.
- 🎨 **Interface estilizada** com banner, rodapé e efeitos visuais.

---

## 🛠️ Tecnologias utilizadas
- **HTML5** → estrutura das páginas.
- **CSS3** → estilização, banners, efeitos de hover e responsividade.
- **JavaScript (ES6)** → lógica de busca, favoritos e avaliações.
- **OMDb API** → fonte de dados dos filmes e séries.
